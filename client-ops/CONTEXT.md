# 💼 Client Operations (`client-ops/`)

> **Your Solutions Architect, Scope-of-Work Generator, and Proposal Closer.**

The `client-ops/` folder is designed for agencies, consultants, freelancers, and service providers. It transforms messy discovery call notes into winning 1-page proposals, bulletproof Scopes of Work (SOW), and smooth client kickoff agendas in minutes.

---

## 📂 Directory Structure

```text
client-ops/
├── README.md                  # This guide
├── CLAUDE.md / SOP.md         # Proposal generation rules and pricing defense
├── examples/                  # Golden benchmarks ("What Good Looks Like")
│   └── proposal_golden.md     # 1-page high-close-rate consulting proposal
├── templates/                 # Reusable frameworks
│   ├── 1_page_proposal.md     # 4-section executive proposal structure
│   ├── scope_of_work.md       # SOW with inclusions, exclusions & milestones
│   └── client_kickoff_agenda.md # 30-minute technical onboarding agenda
└── proposals/                 # Staging directory for generated client documents
```

## ⚡ How to Use It With Your AI

### Example 1: Turn Call Notes into a Winning 1-Page Proposal
> *"Take these rough call notes from my discovery chat with Acme Corp: [paste notes]. Draft a clean 1-page proposal in `client-ops/proposals/` following `proposal_golden.md`."*

### Example 2: Generate a Scope of Work (SOW) that Prevents Scope Creep
> *"Create a formal Statement of Work for a $4,500 automation project. Explicitly list out-of-scope boundaries using `scope_of_work.md`."*

### Example 3: Prepare a Kickoff Meeting Agenda
> *"Generate a 30-minute kickoff call agenda for our new client Sarah using `client_kickoff_agenda.md`."*

## 🎯 The 1-Page Proposal Philosophy
Decision-makers don't read 20-page pitch decks. This engine builds **1-page executive proposals** focused on:
1. **The Core Bottleneck** (proving you listened).
2. **The 3 Measurable Deliverables** (clear, crisp scope).
3. **The Timeline & Investment** (transparent pricing with zero hidden surprises).
