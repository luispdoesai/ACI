# 🎬 Video Engine (`video-engine/`)

> **Your Retention-Driven Video Producer, Scriptwriter, and Packaging Strategist.**

The `video-engine/` turns case studies, technical breakdowns, and creator ideas into high-retention YouTube scripts, viral 30–60s Shorts/Reels/TikToks, and high-CTR title/thumbnail combinations.

---

## 📂 Directory Structure

```text
video-engine/
├── README.md                  # This guide
├── CLAUDE.md / SOP.md         # Retention framework and visual cue notation standards
├── examples/                  # Golden benchmarks ("What Good Looks Like")
│   ├── youtube_script_golden.md   # 8-minute high-retention video script
│   └── short_form_script_golden.md# 45-second viral Short/Reel script
├── templates/                 # Reusable frameworks
│   ├── 10_min_youtube_framework.md# The 5-stage YouTube retention structure
│   └── title_and_thumbnail_matrix.md# 3-angle packaging framework (Curiosity, Contrarian, Proof)
└── scripts/                   # Staging directory for finalized video scripts
```

## ⚡ How to Use It With Your AI

### Example 1: Script a Viral Short / Reel (30–45s)
> *"Draft a 45-second viral Reel showing why typing long prompts to AI every day is a waste of time. Follow `short_form_script_golden.md` and include explicit visual cues alongside spoken lines."*

### Example 2: Outline a 10-Minute YouTube Video
> *"I want to make a 10-minute video explaining how our open-source ACI repo works. Use `10_min_youtube_framework.md` to outline the pacing and write the first 60 seconds (hook + stakes). Give me 3 title and thumbnail options using the packaging matrix."*

### Example 3: Test Packaging Angles First
> *"Generate 3 title & thumbnail combinations for a video about automating client proposals using `title_and_thumbnail_matrix.md`."*

## 👁️ Visual Cue Notation
Every script generated by this engine separates spoken dialogue from visual direction:
- `[VISUAL: Screen recording showing terminal execution...]`
- `[AUDIO: "Stop typing 3-paragraph prompts from scratch..."]`
